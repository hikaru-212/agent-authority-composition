## Research lineage

This repository originated from research questions identified while developing
the Streaming System + Compass project.

It preserves a standalone authority-composition experiment and documentation
package for independent review.

This repository has no Compass runtime dependency and should not be considered
an official Compass component. This lineage statement describes the origin of
the research question; it does not indicate copied external software,
third-party implementation provenance, official project ownership, or
production integration.
